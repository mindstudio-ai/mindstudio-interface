# @mindstudio-ai/interface

**This repository is archived and no longer updated.**

The browser SDK for [Remy](https://goremy.ai) app interfaces (typed calls to backend methods, file uploads, authentication, agent chat and realtime voice) is now developed in the Remy platform's own repository, alongside the API it calls, and released with it. The package is still published to npm under the same name, and its full documentation is on its npm page: [`@mindstudio-ai/interface`](https://www.npmjs.com/package/@mindstudio-ai/interface).

Nothing changes for anyone using it: `npm install @mindstudio-ai/interface` installs the latest release, and new apps start on it.

The history here is kept as a record of how the SDK got to where it is.
